# Agent CLI output

The internal CLI prints plain text regardless of terminal color settings. Structured records remain TOON, and hooks keep their existing JSON format. Errors retain their tag, exit code, path and next step; terminal control characters in diagnostics appear as visible `\u` escapes.

The `rg` and `fd` commands preserve search arguments and exit codes and disable automatic color through their environment. Their output is streamed; terminal control bytes, including those generated by an explicit color flag, are shown as `\u` escapes. Displayed search output is therefore not byte-for-byte identical when it contains controls. Files are unchanged. Use the original file when exact bytes are needed. The browser server's stdio is its MCP protocol, not a CLI report.
