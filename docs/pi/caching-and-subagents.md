# Pi prompt caching, sub-agents and context reuse

Pi 1.4.0, commit `4a080252f06caf63a525d7873c5d94d3c23887e0`. "Inference:" marks my own conclusions.

## Prompt caching

### Controls Pi exposes

- **Retention levels** are `none`, `short`, `long` in the provider layer ([model-schema.js in @earendil-works/pi-ai@1.4.0](https://unpkg.com/@earendil-works/pi-ai@1.4.0/dist/providers/model-schema.js), [types.ts L251](https://github.com/earendil-works/pi/blob/4a080252f06caf63a525d7873c5d94d3c23887e0/packages/ai/src/types.ts#L251)). Each adapter defaults to `short` and switches to `long` when the environment variable `PI_CACHE_RETENTION=long` is set (Anthropic 1h, OpenAI 24h per the env doc) ([environment-variables.md L88](https://github.com/earendil-works/pi/blob/4a080252f06caf63a525d7873c5d94d3c23887e0/packages/coding-agent/docs/environment-variables.md#L88), [anthropic-messages.ts L67-L90](https://github.com/earendil-works/pi/blob/4a080252f06caf63a525d7873c5d94d3c23887e0/packages/ai/src/api/anthropic-messages.ts#L67-L90), [openai-responses.ts L78-L90](https://github.com/earendil-works/pi/blob/4a080252f06caf63a525d7873c5d94d3c23887e0/packages/ai/src/api/openai-responses.ts#L78-L90)).
- The 1.4.0 `settings.md` has **no retention key**; only `cacheWarming` and `showCacheMissNotices` relate to caches ([settings.md L20-L23](https://github.com/earendil-works/pi/blob/4a080252f06caf63a525d7873c5d94d3c23887e0/packages/coding-agent/docs/settings.md#L20-L23)). `none` and per-request `cacheRetention` are reachable only through the pi-ai API or SDK options, not through `settings.json` (Inference: from the absence of such a key in the settings reference and in `settings-manager.ts`).
- **Session id as the affinity key.** The coding agent passes `sessionId: sessionManager.getSessionId()` into every request ([sdk.ts L427](https://github.com/earendil-works/pi/blob/4a080252f06caf63a525d7873c5d94d3c23887e0/packages/coding-agent/src/core/sdk.ts#L427)). When retention is `none` the session id is not sent as a cache key ([openai-responses.ts L373](https://github.com/earendil-works/pi/blob/4a080252f06caf63a525d7873c5d94d3c23887e0/packages/ai/src/api/openai-responses.ts#L373), [anthropic-messages.ts L623](https://github.com/earendil-works/pi/blob/4a080252f06caf63a525d7873c5d94d3c23887e0/packages/ai/src/api/anthropic-messages.ts#L623)).
- **Model metadata** `promptCache: { short, long }` (seconds) declares a provider's best-effort cache lifetime; only tiers with a lifetime are eligible for warming ([models.md L104-L112](https://github.com/earendil-works/pi/blob/4a080252f06caf63a525d7873c5d94d3c23887e0/packages/coding-agent/docs/models.md#L104-L112), [custom-provider.md L147](https://github.com/earendil-works/pi/blob/4a080252f06caf63a525d7873c5d94d3c23887e0/packages/coding-agent/docs/custom-provider.md#L147)).
- **Cache warming:** `cacheWarming` = `off` / `streaming` (default) / `idle`, global setting only. It runs only when the model declares a lifetime and Pi estimates at least $0.05 avoided cost; refresh usage counts toward session totals; extensions can override with the `cache_warming_decision` event ([settings.md L21-L23](https://github.com/earendil-works/pi/blob/4a080252f06caf63a525d7873c5d94d3c23887e0/packages/coding-agent/docs/settings.md#L21-L23), [extensions.md L234](https://github.com/earendil-works/pi/blob/4a080252f06caf63a525d7873c5d94d3c23887e0/packages/coding-agent/docs/extensions.md#L234)).
- Summarization requests (compaction, branch summary) disable prompt-cache writes ([compaction.md L23](https://github.com/earendil-works/pi/blob/4a080252f06caf63a525d7873c5d94d3c23887e0/packages/coding-agent/docs/compaction.md#L23)).

Cache-friendly behaviours documented by Pi: changing prompt sections lets Pi append a transcript delta, while returning a full `systemPrompt` replaces the prompt ([extensions.md L216](https://github.com/earendil-works/pi/blob/4a080252f06caf63a525d7873c5d94d3c23887e0/packages/coding-agent/docs/extensions.md#L216)); tool-set changes append to the transcript and can invalidate the prefix on providers that cannot express the change ([extensions.md L301](https://github.com/earendil-works/pi/blob/4a080252f06caf63a525d7873c5d94d3c23887e0/packages/coding-agent/docs/extensions.md#L301)); a thinking-level change keeps the cache on GPT-6 with an API key but not with ChatGPT sign-in ([CHANGELOG.md L64-L71](https://github.com/earendil-works/pi/blob/4a080252f06caf63a525d7873c5d94d3c23887e0/packages/coding-agent/CHANGELOG.md#L64-L71), [models-configuration.md L156](https://github.com/earendil-works/pi/blob/4a080252f06caf63a525d7873c5d94d3c23887e0/packages/coding-agent/docs/models-configuration.md#L156)); switching models between turns loses the prompt cache ([virtual-models.md L84](https://github.com/earendil-works/pi/blob/4a080252f06caf63a525d7873c5d94d3c23887e0/packages/coding-agent/docs/virtual-models.md#L84)).

Inference for HolyAgent: the session id is the cache key on most providers, so _reusing the same Pi session for the same Assignment_ is what preserves caching across continuations, while every fresh `pi` process with a new session id starts with a cold cache for its (identical) system prompt prefix on key-based providers. HolyAgent cannot set retention per Assignment through Pi's settings; it can set `PI_CACHE_RETENTION=long` in the environment of the Pi process it spawns.

## Sub-agents

### Built in?

No. Pi "skips features like sub-agents and plan mode" and tells users to build or install them ([README L19](https://github.com/earendil-works/pi/blob/4a080252f06caf63a525d7873c5d94d3c23887e0/README.md#L19)); the 0.73.1 README adds "Spawn pi instances via tmux, or build your own with extensions" ([0.73.1 README L472](https://github.com/earendil-works/pi/blob/781152fc24841dc54b22284514604048ebe5e2c9/packages/coding-agent/README.md#L472)).

### Official example: `examples/extensions/subagent`

- A `subagent` tool with three modes: single `{ agent, task }`, parallel `{ tasks }` (max 8 tasks, 4 concurrent), chain `{ chain }` with a `{previous}` placeholder ([subagent/README.md L91-L97](https://github.com/earendil-works/pi/blob/4a080252f06caf63a525d7873c5d94d3c23887e0/packages/coding-agent/examples/extensions/subagent/README.md#L91-L97), [index.ts L34-L35](https://github.com/earendil-works/pi/blob/4a080252f06caf63a525d7873c5d94d3c23887e0/packages/coding-agent/examples/extensions/subagent/index.ts#L34-L35)).
- Each call spawns a separate `pi` process with `--mode json -p --no-session`, plus `--model`, `--tools` and `--append-system-prompt` from the agent definition ([index.ts L247-L260, L298-L344](https://github.com/earendil-works/pi/blob/4a080252f06caf63a525d7873c5d94d3c23887e0/packages/coding-agent/examples/extensions/subagent/index.ts#L298-L344)). Context is isolated per subagent and discarded afterwards (`--no-session`); the parent receives the final output, capped at 50 KB per parallel task ([subagent/README.md L5-L12, L112-L116](https://github.com/earendil-works/pi/blob/4a080252f06caf63a525d7873c5d94d3c23887e0/packages/coding-agent/examples/extensions/subagent/README.md#L5-L12)).
- Agents are Markdown files with YAML frontmatter (`name`, `description`, `tools`, `model`) under `~/.pi/agent/agents/` and, opt-in, project `.pi/agents/`; without `model` the subagent inherits the dispatcher's model and thinking level ([subagent/README.md L125-L151](https://github.com/earendil-works/pi/blob/4a080252f06caf63a525d7873c5d94d3c23887e0/packages/coding-agent/examples/extensions/subagent/README.md#L125-L151)). Project agents are repo-controlled prompts, so the example asks for confirmation unless the project is trusted ([subagent/README.md L55-L65](https://github.com/earendil-works/pi/blob/4a080252f06caf63a525d7873c5d94d3c23887e0/packages/coding-agent/examples/extensions/subagent/README.md#L55-L65)).
- Workflow prompts (`/implement`, `/scout-and-plan`, `/implement-and-review`) chain agents ([subagent/README.md L157-L163](https://github.com/earendil-works/pi/blob/4a080252f06caf63a525d7873c5d94d3c23887e0/packages/coding-agent/examples/extensions/subagent/README.md#L157-L163)).

### In-process and durable options

- The SDK creates independent `AgentSession`s in one process; the docs refer to "in-process subagents" when explaining the codemode worker limit (`PI_CODEMODE_MAX_WORKERS`, default 2) ([sdk.md L3-L25](https://github.com/earendil-works/pi/blob/4a080252f06caf63a525d7873c5d94d3c23887e0/packages/coding-agent/docs/sdk.md#L3-L25), [environment-variables.md L87](https://github.com/earendil-works/pi/blob/4a080252f06caf63a525d7873c5d94d3c23887e0/packages/coding-agent/docs/environment-variables.md#L87), [CHANGELOG.md L40](https://github.com/earendil-works/pi/blob/4a080252f06caf63a525d7873c5d94d3c23887e0/packages/coding-agent/CHANGELOG.md#L40)).
- `@earendil-works/pi-durable` (experimental) has owned child conversations: a subagent tool creates a child conversation tied to the task, reuses it on rerun, and aborts it with its parent ([durable README L636-L681](https://github.com/earendil-works/pi/blob/4a080252f06caf63a525d7873c5d94d3c23887e0/packages/durable/README.md#L636-L681)). It is a separate harness, not the `pi` CLI, and "the API changes without notice between releases" ([durable README L3](https://github.com/earendil-works/pi/blob/4a080252f06caf63a525d7873c5d94d3c23887e0/packages/durable/README.md#L3)).

Compaction keeps long-lived sessions within the model window and leaves the original entries in the JSONL tree ([sessions.md L40-L46](https://github.com/earendil-works/pi/blob/4a080252f06caf63a525d7873c5d94d3c23887e0/packages/coding-agent/docs/sessions.md#L40-L46)).

Inference for HolyAgent: model an Assignment as one Pi session whose id is derived from the Assignment id (for example `--session-id <assignment-id>`), so a follow-up, a rework request or a resume after interruption becomes "same session, new prompt". That gives context reuse and a stable cache key without HolyAgent storing transcripts, and it contrasts with the shipped example, which deliberately throws the transcript away. The `--session-id` charset rule (letters, numbers, `.`, `_`, `-`, starting and ending alphanumeric) must be respected ([cli.md L92-L105](https://github.com/earendil-works/pi/blob/4a080252f06caf63a525d7873c5d94d3c23887e0/packages/coding-agent/docs/cli.md#L92-L105)).
