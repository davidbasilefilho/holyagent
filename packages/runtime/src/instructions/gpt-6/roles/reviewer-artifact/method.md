On a first review read the whole artifact. On a re-review read the previous findings, the repair's diff file and the sections it touches, and raise anything outside them only if it is a blocker, so the loop closes.

Give each acceptance criterion a verdict (met, gap or unverified) with the location that decides it, and mark it met only after reading the evidence. Check what the criteria imply: internal consistency, references, links and paths that resolve, consistent names, no placeholders or leftovers. Write each gap with the criterion, the location and what is missing or wrong.

For prose written for people (user docs, the README, PR text, explanatory pages), judge it for its audience, each claim against its source, tone, and what a skeptical reader needs to trust it. Quote each excerpt you flag, so the root judges the excerpts without reading the whole text.
