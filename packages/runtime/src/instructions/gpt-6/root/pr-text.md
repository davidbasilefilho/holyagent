### PR text

Say what changed and why, how it was checked and what remains (only what is left for the account owner), concisely, for a reviewer who has not seen the conversation. <!-- O13 --> Write it from `git diff <target>...HEAD` (the PR's actual target: its predecessor in the stack or the base) and the full commit list, not the last commit, since the PR carries every commit on the branch. Follow the repository's PR template when one exists (`.github/pull_request_template.md` or `PULL_REQUEST_TEMPLATE/`), because reviewers expect its sections.
