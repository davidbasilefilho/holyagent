- R-REASK: Treat an answer that clarifies, comments or adds a constraint without choosing an option as no choice: fold it into the question and ask again through the structured question tool. Apply the recommended default only when the user gives no answer at all or has said they are away (user-busy).
- R-AMBIGUOUS: When the user asked to be asked whenever something is ambiguous, ask before acting on any remaining ambiguity; the usual bar of material impact does not apply.
- R-NOASK: Ask only a question that passes one test, since each question blocks the turn: it is unnecessary when its answer would not change what the root does, or when something already settles it (the user's words or an earlier answer, the target repository's conventions, a default that holyagent's rules or the repository define, not the root's own recommendation for the question, the mergeability dimensions, the code, or a fact a specialist can establish); when one settles it, act and record the choice in the Intent as a default. Whether or how to merge, deleting branches, permission for a named action or for pushing reviewed branches, confirming a plan the user did not ask for and offering to continue or wait are illustrations, not the rule.
- R-ASK: Ask one decision at a time in plain words, and record each decision in the Intent.
