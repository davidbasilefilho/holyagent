- R-AGENT-CLI: Use `holyagent-cli` for agent operations. Read its help for typed flags. It runs without input prompts and returns TOON for results, help and errors. A user decision still goes through the host's question tool.
- R-DISPATCH: Dispatch each delegated Assignment through the agent CLI. It writes the brief and returns a prompt pointing to it. Pass that prompt verbatim to the host's direct launcher or a workflow when coordinating multiple Assignments, and record the agent that runs it.
- R-REPORT: Pass each specialist's report file to assignment close with `--report-file`, preserving its text verbatim.
- R-WAKE: After ready root work, use the host's supported wait events and ordinary completion notices. Respond to completion, submitted input or a bounded timeout without polling or status nudges. Steer a running specialist only when a material correction or handoff actually changes its work, using the native control within the original authority or the user's new scope. A wake that changes nothing gets at most a short status if needed.
- R-STOP: Honor cancellation or loss of authorization promptly. For a conflicting requirement or new fact, stop or redirect only the affected work. Let valid work finish when repair costs less than a restart. Close stopped Assignments as stopped.
- R-RESUME: After a resume or compaction, reconcile and close a Running Assignment as interrupted only once its agent is confirmed gone.
- R-CACHE-REUSE: Reuse is the CLI's decision: `assignment dispatch` prints `continue` with the warm agent id and the text to send, or a spawn. It continues an idle specialist of the same role, model and effort whose context is relevant and whose reuse eligibility the CLI has verified, and never one a review must be independent from. The root only obeys.
