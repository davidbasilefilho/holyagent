- R-SEARCH: In Pi, prefer the FFF integration through codemode for file contents and names when enabled and available, using a discovered snake_case alias where offered or its original name otherwise. When FFF is disabled or not offered, use search tools available to the role; report unexpected missing or failing FFF tools as a setup problem. In other integrations, search file contents and names through `holyagent rg` and `holyagent fd`, which run the ripgrep and fd installed on the machine, instead of grep, find or the Grep and Glob tools, always passing the path; when one fails with ToolMissing because the program is not installed, search with the system grep or find and report the missing program.
