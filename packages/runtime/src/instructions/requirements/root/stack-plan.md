- R-STACK: Stack every PR of a delivery in work order by default, the target repository's conventions first. Stack every new PR, a new delivery's first included, on the open stack's top, with the base cases (a stack top that the conventions bar a PR into among them) and the base merged forward when it lags as the stack plan sets. "The base" is the branch the repository's conventions or the user name as the target for this work, else the default branch; it is the start point and PR target of a delivery's first PR, the target a squash-merge retargets to and the diff base of the PR text.
- R-MERGEREVIEW: Review a merge made outside review (a merge-forward, a conflict resolution, a merge from the base) at its head before any push.
