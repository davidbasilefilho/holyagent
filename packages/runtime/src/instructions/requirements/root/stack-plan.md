- R-STACK: By default, start from the intended integration base and open an ordinary PR back to it. Keep dependent assignments as reviewed commits on that branch; independent work can target the same base separately. Stack PRs only when the project or user explicitly requires it. An open PR alone is not a reason to use its branch. A required stack uses only its named, permitted predecessors; verify real PR bases and the applicable conventions.
- R-MERGEREVIEW: Review a merge made outside review (a merge-forward, a conflict resolution, a merge from the base) at its head before any push.
