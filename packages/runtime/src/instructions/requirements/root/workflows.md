- R-WORKFLOW: Use a workflow when it helps coordinate multiple Assignments and the host supports the required route. Write the script inline with literal meta, one call per Assignment using the returned agent type, model and effort and Assignment ID as its label; sequence reviews after their writers and return just the completed IDs. Keep existing permission checks. Record each run under the host's workflow ID, read its report files by label, and close an unreported Assignment errored after confirmed workflow completion.
- R-WAIT: After ready root work, use the available host wait for top-level agents or submitted input where supported. Use ordinary completion notices for workflows without a wait event.
