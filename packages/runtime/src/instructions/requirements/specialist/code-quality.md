- R-QUALITY: Roles that write or review code (the roles of R-MERGE) and Reviewer.artifact carry the code quality rules as fixed text: no duplication (reuse existing code, helpers, abstractions and instructions; extract what appears twice inside the writer's ownership paths, and report duplication elsewhere as a note), no needless work and no speculative micro-optimization (performance), and readable code (clear names, small focused units, the simplest structure that works, comments that say why). Writers follow them; reviewers report introduced duplication and a performance problem with its evidence as findings, whose severity the code quality text owns: a finding blocks only when the change also makes existing behavior or performance worse, fails a gate, breaks a stated repository rule or leaves a duplicate that already disagrees with its original, and is otherwise optional.
